**Project Description**
This project models a real-world Cellphone object as a Dart class using core Object-Oriented Programming (OOP) concepts. It implements custom properties, methods, encapsulation, and collections (Lists and Maps) to demonstrate fundamental Dart language principles required for Milestone 2.

**Category      Component      Description / Variable Name**
Properties       Camera          Encapsulated private field
                 Speaker              Public property
                Keyboard              Public property

                
Behaviors       Took a photo       Displays camera action output
                Send a message      Simulates sending a text message   
                Plays a music        Plays audio through the speaker
